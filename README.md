# 💖 Virtual AI Lover

一个基于 HTML / CSS / JavaScript 开发的虚拟 AI 恋人 Web 应用。  
项目模拟 AI 情感陪伴产品，支持角色聊天、情绪状态、好感度、长期记忆等功能。

## 🚀 项目功能

- 💬 AI 虚拟恋人聊天
- 🧠 长期记忆系统
- ❤️ 好感度系统
- 😊 情绪状态系统
- 🎭 多角色切换
- 💾 本地聊天记录保存
- 🌌 科技感 UI 界面
- 📱 响应式布局（支持移动端）

## 🌐 GitHub Pages 部署

1. 新建 GitHub 仓库
2. 上传项目文件
3. 进入：

```txt
Settings → Pages
```

4. Source 选择：

```txt
main branch
```

5. 保存后等待生成网址
