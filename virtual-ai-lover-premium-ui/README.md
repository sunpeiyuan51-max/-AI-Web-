# Virtual AI Lover Premium UI｜虚拟 AI 恋人高级版

这是一个完整可运行的虚拟 AI 恋人 Web 项目，界面更简洁，更像真实聊天软件。

## 功能

- 虚拟角色聊天
- 多角色切换
- 好感度系统
- 情绪系统
- 记忆系统
- 聊天记录本地保存
- 手机端适配
- 科技感 + 情感陪伴风格 UI

## 运行方式

双击 `index.html` 即可运行。

## 文件说明

- `index.html` 页面结构
- `style.css` 页面样式
- `script.js` 交互逻辑
- `api-upgrade-example.js` 后续接入 DeepSeek API 示例

## 简历项目描述

独立开发虚拟 AI 恋人 Web 应用，使用 HTML、CSS、JavaScript 实现聊天交互、人设系统、好感度系统、情绪状态、本地记忆和聊天记录持久化，支持多角色切换与响应式布局，可部署至 GitHub Pages 展示。
